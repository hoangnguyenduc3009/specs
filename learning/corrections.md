# Correction log

Chưa có correction thực tế. Thêm mỗi sự kiện thành một mục, không ghi đè lịch sử.
Mẫu để dùng khi có feedback:

## COR-<id> — <tóm tắt>

- Run / Change-Id / skill@version / bước bị vướng:
- AI trước điều chỉnh (trích ngắn hoặc link revision):
- Dev điều chỉnh / nguồn và thời điểm:
- Lý do Dev cung cấp:
- Bằng chứng / revision / giới hạn:
- Nguyên nhân AI dự kiến (chưa phải kết luận):
- Xác nhận: pending / accepted / rejected; người và thời điểm:
- Kết quả: chưa sửa / đã sửa hồ sơ / đã kiểm chứng / chưa giải quyết:
- Bằng chứng kiểm chứng và hành vi thực tế (nếu có):
- Nơi cần cập nhật: task / kiến thức Arena / đề xuất skill / chưa rõ:
- Liên kết đề xuất/case và lịch sử cập nhật:
